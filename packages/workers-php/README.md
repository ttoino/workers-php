# workers-php

PHP on Cloudflare Workers, Durable Objects and Containers — run a Laravel
or Symfony app inside a Workers Container while D1, R2 and Email ride the
worker's bindings over intercepted outbound HTTP.

```sh
npm install workers-php
```

Full documentation lives in the [repository
README](https://github.com/ttoino/workers-php#readme).
